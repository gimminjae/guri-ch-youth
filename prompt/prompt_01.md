# 프로젝트 수정 사항

- 메인 화면에서 기도 목록을 보여줄 때 그리드 리스트 형식으로 보여주도록
- 필드별로 리스트 행에서 노출되는 순서를 설정할 수 있도록
- 필드 유형을 정할 때, '글' 유형을 '짧은 텍스트'와 '글'로 나누어 관리
- 메인 화면에서 그룹화, 필터링 UI는 https://gurich-prayer.netlify.app/ 이 사이트를 참고해서 만들어줘
- 리스트에서 엑셀 파일 다운로드, 엑셀 파일로 데이터 업로드 기능을 추가해줘
- 필드 설정시에 여러개의 값(selectbox, multibox)을 설정할 때 각각의 옵션별 색상을 설정할 수 있도록 해줘. 그래서 배지나 강조색 설정시에 해당 옵션은 설정된 색깔로 표시될 수 있도록
- 색상을 선택하는 것은 colorpicker 외부 라이브러리를 사용하도록 해
- 필드에 '집계' 옵션을 세팅할 수 있도록 해서 해당 필드의 값인 로우가 각각 몇개인지 표현하는 UI를 추가해줘 https://gurich-prayer.netlify.app/ 이 사이트의 UI를 참고해
