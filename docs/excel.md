# 엑셀 사용 안내

목록의 **엑셀** 버튼에서 현재 조회 결과와 작성 양식을 내려받는다. 추가·수정은 상단 참여 모달에서 관리자 또는 부관리자로 인증한 후 사용할 수 있다.

## 다운로드

- 현재 필터에 맞는 **전체 행**을 관리자 필드 순서로 내보낸다. 현재 목록 페이지에 한정되지 않는다.
- 목록 표시에서 숨긴 필드도 전체 값이 포함된다. 다중 선택 그룹에 속한 같은 기도부탁은 한 번만 포함한다.
- `기도부탁` 시트에는 데이터, `집계` 시트에는 전체·값별·그룹별 건수, `작성 안내`에는 입력 방법이 있다. 화면에서 여러 페이지로 나뉜 집계값도 파일에는 모두 포함한다.
- 숫자·불리언·날짜는 해당 셀 형식, 텍스트는 문자열로 보존한다. 텍스트의 `=` 등은 수식으로 변환하지 않는다.
- 첨부는 앱의 `/api/files/UUID` 링크 문자열로 표시한다. S3 주소·키·파일 내용은 포함하지 않는다.
- 필드 식별 정보와 기도부탁 ID·수정 버전·목록 표시 설정은 숨겨진 시트와 열에 보관한다. 수정용 파일에서는 유지한다.

## 새 자료 추가

1. 작성 양식을 내려받아 `기도부탁` 시트의 머리글 아래에 내용을 작성한다.
2. 파일을 선택하고 **새로 추가** 모드에서 열과 필드를 연결한다. 메타데이터가 없는 일반 파일은 이름 자동 연결 후 수동 조정할 수 있다.
3. **검증하고 미리보기**를 누른다. 오류가 있으면 행 번호와 필드명을 확인하여 파일을 수정하고 다시 선택한다.
4. 내용과 건수를 확인한 뒤 **N건 추가 확정**을 누른다.

새 자료의 ID는 비워 둔다. 기존 자료를 내려받은 파일은 ID가 있으므로 추가 모드에서 거부된다. 파일에 없는 필드나 선택지는 자동 생성하지 않는다. 새 자료의 첨부파일 셀은 비워 둔다.

## 기존 자료 수정

1. 현재 자료를 내려받고 값만 편집한다. ID와 수정 버전 열을 유지한다.
2. **기존 자료 수정** 모드를 고르고 ID·수정 버전과 수정할 필드를 연결한다.
3. 미리보기에서 변경값과 **값 삭제** 표시를 확인한 후 확정한다.

- 연결하지 않은 필드는 기존 값을 유지한다.
- 연결한 열의 빈 셀은 값을 삭제한다. 한 행의 모든 내용을 비울 수는 없다.
- 첨부는 빈 셀·연결하지 않음이면 유지된다. 원래 게시물의 첨부 링크도 유지할 수 있지만, 추가·교체·해제는 엑셀로 할 수 없다.
- 파일에 없는 게시물은 삭제하지 않는다. ID 없는 행을 자동 추가하지 않는다.
- 다른 사람이 수정했거나 필드 설정이 바뀌면 전체 저장을 거부한다. 새 파일을 내려받거나 미리보기를 다시 진행한다.
- 모든 행을 하나의 트랜잭션으로 저장한다. 중간 실패 시 부분 저장하지 않으며 같은 확인 작업을 재요청해도 중복 추가되지 않는다.

## 값 입력과 제한

| 항목 | 규칙 |
| --- | --- |
| 텍스트 | 한글·앞자리 0·줄바꿈 보존. 앞자리 0은 Excel의 텍스트 셀 사용. 짧은 텍스트는 줄바꿈 불가, 두 유형 모두 기존 10,000자 제한 |
| 선택지 | 등록된 이름만 사용. 다중 선택은 `학업,진로`처럼 쉼표로 구분 |
| 숫자 | 숫자 셀 또는 숫자 문자열. `0` 유지 |
| 예/아니오 | 불리언 셀 또는 `TRUE`, `FALSE`, `예`, `아니오`. `false` 유지 |
| 날짜 | 날짜 셀 또는 `YYYY-MM-DD` |
| 파일 형식 | `.xlsx`만 지원. 수식·매크로·외부 참조·하이퍼링크 셀·병합 셀은 거부. 일반 문자열로 적은 앱 첨부 링크는 허용 |
| 파일·데이터 | 파일 5MB, 데이터 500행, 동적 필드 40개 + 메타데이터 3열 |
| 분석 | 압축 해제 20MB, ZIP 160개 항목, 시트당 150,000셀·30,000행, 분석 worker 128MB·10초. 데이터 시트는 501행(머리글 포함)·43열로 별도 제한 |
| DB 요청 | 변환한 JSON 최대 512KiB. 파일 크기가 작아도 본문이 길면 나누어 업로드 |
| 다운로드 | 필터 결과 500건·본문 합계 8MB, 그룹 집계 JSON 8MB 및 생성 XLSX 제한. 초과 시 필터 범위를 줄이거나 그룹화 해제. 일부 행을 조용히 누락하지 않음 |
| 확인 작업 | 현재 로그인 세션에 묶여 30분간 유효. 미리보기 시간당 30회, 확정 시간당 10회. 일반 개별 작성 제한과 별도 |

업로드 파일 원본은 S3나 공개 URL에 저장하지 않는다. DB에는 검증된 가져오기 요청과 중복 방지 결과만 비공개로 보관한다.
